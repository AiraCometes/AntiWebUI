# Spike: question

<!-- Phase 4 and later. Save as docs/fork/research/spikes/<kebab-case-question>.md.
     Spike code lives on a branch or under a throwaway path and is not merged as product code. -->

- Date: YYYY-MM-DD
- Time box: hours or days
- Branch or commit: where the spike code lives
- Decision it feeds: ADR-NNNN or OpenSpec change

## Question

One question with a yes/no or a measurable answer.

## Hypothesis

What we expect, and what result would prove it wrong.

## Method

Setup, platforms, commands, and data, so the spike can be repeated.

## Results

Measurements (link a benchmark report when timing is involved), screenshots, and failures.

## Conclusion

Answer to the question, with the evidence label. State the limits of what was shown.

## Follow-up

What to do next: an ADR, a change, another spike, or nothing.
